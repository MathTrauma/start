직각삼각형의 합동

대각선 $AC$ 는 $\angle C$ 의 이등분선이고 $\angle B = \angle D = 90^\circ$ 이므로 $$\triangle ABC \equiv \triangle ADC$$ 이다. 따라서 $\angle DAC = \angle BAC $ 이고 $\overline{AB}=5=\overline{AD}$ 를 얻는다.

마름모 찾기(?)

선분 $DH$ 와 $AC$ 의 교점을 $E$ 라 하자. 선분 $AB$ 와 $DH$ 는 평행이므로 엇각으로 $\angle BAC = \angle DEA$ 가 성립한다. 또한 $\triangle CDE \equiv \triangle CBE $ 에서 $\angle DEA = \angle BEA$ 이다. 결국, $ \overline{DE} = 5$ 도 얻는다. (이 문제에서는 사용되지 않지만 $\overline{BE} =5$ 도 알 수 있다.)

닮음

두 직각삼각형 $EHC$, $ABC$ 는 닮았으므로, $\overline{EH} = x$ 로 두면, $\overline{HC} = 2x$ 이다. 직각삼각형 $DHC$ 에 피타고라스 정리를 적용 $$10^2 = (5+x)^2 + (2x)^2 \;\Longrightarrow\; x= 3$$ 를 얻고, 이로부터 $\sin \angle CDH = \dfrac 3 5$.
