Step 1 : 수족삼각형의 각이등분선

$AFHE$ 는 $\angle AFH = \angle AEH = 90°$ 이므로 한 원 위의 네 점이다. 같은 호 $AH$ 에 대한 원주각이므로 $\angle HFE = \angle DAC$. 마찬가지로 $BDHF$ 도 한 원 위의 네 점이고 $\angle DFH = \angle DBH = \angle CBE$. 따라서 $FH$ 는 수족삼각형 $\triangle DEF$ 에서 $\angle DFE$ 의 이등분선이다.

Step 2 : 내각이등분선 비례

$FH$ 가 $\angle DFE$ 의 이등분선이므로 $$\overline{FD} : \overline{FP} = \overline{HD} : \overline{PH} = 28 : x$$ 여기서 $x = \overline{PH}$ 로 놓았다.

Step 3 : 외각이등분선

$AF \perp BF$ 이고 $FH$ 는 $\angle DFE$ 의 이등분선이므로 $FA$ 는 $\angle DFE$ 의 외각이등분선이다. 외각이등분선 성질에 의해 $$\overline{FD} : \overline{FP} = \overline{AD} : \overline{AP} = (x + 58) : 30$$

Step 4 : 연립

두 비례식에서 $$28 \cdot 30 = x(x + 58)$$ $$x^2 + 58x - 840 = 0$$ $$(x + 70)(x - 12) = 0$$ $x > 0$ 이므로 $\overline{PH} = 12$.
