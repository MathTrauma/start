직선 $AI$ 는 $\angle A$ 의 이등분선이므로, 외접원과 다시 만나는 점 $S$ 는 점 $A$ 를 포함하지 않는 호 $BC$ 의 중점이다.

호 $SC$ 에 대한 원주각에서 $$\angle SBC = \angle SAC = \tfrac{1}{2}\angle A.$$ 또 $BI$ 는 $\angle B$ 의 이등분선이므로 $\angle CBI = \tfrac{1}{2}\angle B$ 이고, $$\angle SBI = \angle SBC + \angle CBI = \tfrac{1}{2}\angle A + \tfrac{1}{2}\angle B.$$

한편 $\angle BIS$ 는 삼각형 $ABI$ 의 외각이므로 $$\angle BIS = \angle IAB + \angle IBA = \tfrac{1}{2}\angle A + \tfrac{1}{2}\angle B.$$

따라서 $\angle SBI = \angle BIS$ 이므로 삼각형 $SBI$ 는 $\overline{SB} = \overline{SI}$ 인 이등변삼각형이다.

$$\therefore \ \overline{BS} = \overline{IS} = 8.$$
